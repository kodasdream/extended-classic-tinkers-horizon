# Extended Classic Tinkers for Horizon

Tinkers' Construct as it was in Minecraft 1.12.2, rebuilt for [Horizon](https://github.com/horizon-rust/horizon) (Minecraft: Java Edition 26.3 in Rust), with the extra materials of the 1.12 Tinkers addons (TAIGA, PlusTiC and others) and Tinkers' Tool Leveling.

It sits on top of [Ore Overhaul Long Climb](https://github.com/kodasdream/ore-overhaul-long-climb), which it needs: Tinkers' mining levels 0 to 12 are spread over Long Climb's 50 tiers.

**Status: alpha.**

## What's in it

- The smeltery: controller, seared bricks, tanks, drains, faucets, casting tables and basins, alloying, the Tinker Tank and the seared furnace.
- The Stencil Table, Part Builder, Tool Station and Tool Forge, patterns and casts.
- 23 modular tools (pickaxe, hammer, excavator, lumber axe, broadsword, rapier, katana, bows, arrows and more) from 32 parts, with stats from their materials.
- 197 materials, 143 traits and the 1.12 modifiers (redstone, quartz, lapis, diamond, emerald and the rest).
- Tool Leveling: tools gain XP as they're used, and each level gives a modifier slot.
- Slime islands, slime boots, the slime sling.

## Not yet

- Bows and arrows use vanilla's bow mechanics with Tinkers' arrows' damage and traits; draw speed and range don't follow the materials yet.
- A few traits only approximate mods that aren't here (Blood Magic, Botania mana, Astral Sorcery): see the code in `native/ddsstinkers/traits.rs`.
- The smeltery holds at most 45 items; molten metal buckets, channels and the drying rack are missing.

## Install

You need Horizon's Nightly from 2026-11-04 or newer, and Ore Overhaul Long Climb 0.5.0 with its native mod.

1. From [Releases](https://github.com/kodasdream/extended-classic-tinkers-horizon/releases), put `extended-classic-tinkers-0.5.0.hmod` in `horizon-mods/` and `extended-classic-tinkers-0.5.0.hnmod` in `horizon-native-mods/`.
2. Build the game. Native mods run with full access to your computer, so read the source in `native/ddsstinkers` first:

```bash
horizon-launcher native-build --ignore-pins --trust-native-code
```

3. Turn it on in **Options → Mods** and restart. `/tinkers tool pickaxe wood iron iron` makes a tool for testing.

Its mod id is still `ddsstinkers`, so worlds that have its items keep them.

## What's where

- `mod/ddsstinkers`: the content mod (blocks, items, recipes, slime islands), generated by Long Climb's `tools/generator/tinkers.py`.
- `native/ddsstinkers`: the smeltery, tables, modular tools, traits and tool leveling.
- `tests/`: scripts that drive a real game to check the smeltery, tools and every trait.
